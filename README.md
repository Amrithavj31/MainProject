# MainProject

## Overview
This project covers manual and automated testing of the AcademyBugs website—a training platform designed to help QA testers practice finding real-world bugs. The site includes intentionally broken features across modules like forms, carts, search, and UI.

## Testing Scope

### Manual Testing
Link redirection, form validation, UI checks, responsiveness, bug reporting

### Automation Testing
Repetitive flows (login, forms, cart, navigation) using Selenium

### Areas Covered
Dashboard, bug examples, finding bugs, report bugs, footer

## Included Documents
Test plan documents – Detailed test strategy, scope, approach, and schedule
Manual test case documentation  – Step-by-step manual test scenarios
Automation scripts – Selenium scripts for key test flows
Bug Reports – Logged defects and status
